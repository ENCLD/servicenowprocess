  the KPI tiles now render without the "Invalid configuration" error.

  What was wrong: COUNT_DISTINCT isn't a valid aggregateFunction on this
  instance — it only accepts COUNT, SUM, etc. The two single-score KPI tiles
  ("Companies With an Active Contract" and "Places Allocated") were using
  COUNT_DISTINCT on the company/consultant reference fields, which the platform
  rejected.

  Fix: Replaced them with the confirmed-valid aggregate functions:
  - Active Contracts — plain COUNT of active assignment rows
  - Total Capacity Allocated (%) — SUM of allocation_percentage across active
    rows (same pattern already working in the main bar chart)

  This slightly changes the meaning (row counts instead of distinct
  company/consultant counts) since distinct-counting isn't supported here — let
  me know if you'd rather I find another way to get a true distinct
  company/consultant count instead.
